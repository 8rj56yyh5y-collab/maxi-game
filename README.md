# MAXI STRIKE

Тактический шутер в браузере в духе мобильных шутеров (Critical Ops, Standoff 2). Рассчитан в первую очередь на телефоны и планшеты (сенсорное управление, гироскоп), работает и на ПК с мышью и клавиатурой. Пока что — бои с ботами.

## Как запустить

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. С телефона в той же сети Wi‑Fi: `http://<IP-компьютера>:8000`.

## Режимы

- **Закладка бомбы** — раунды (MR6–MR24), экономика, меню закупки, бомба на точках A/B, набор сапёра, смена сторон.
- **Командный бой** — возрождение, оружие из «Снаряжения».
- **Каждый сам за себя** — все против всех.
- **Гонка вооружений** — новое оружие за каждое убийство, финал — нож.

- **Рейтинговая игра** — закладка бомбы 5×5 (MR12) на рейтинг: звания Бронза → Серебро → Золото → Платина → Алмаз → Мастер → Легенда, сезоны, сила ботов растёт со званием.

Боты: 4 уровня сложности; закупаются, закладывают и обезвреживают бомбу, держат точки, кидают гранаты.

## Карты

Городские карты по мотивам реальных мест: **Токио** (ночной неон, переулок ёкотё, святилище), **Старый город** (европейская площадь на закате, церковь, канал), **Бруклин** (авеню, пожарные лестницы, парк), **Санторини** (белые домики над морем), **Париж** (бульвар, кафе, Эйфелева башня), **Киото** (Гион, пагода, осенний сад с прудом), **Майами** (ночной Оушен-драйв, ар-деко, пальмы, пляж), а также **Оазис** и **Порт**. Ночные карты освещены динамическими фонарями и неоном. В меню выбранная карта видна живым фоном.

## Оружие и предметы

- 20 видов оружия с ценами: 4 пистолета, 4 ПП, 4 винтовки, 4 снайперские, 4 дробовика.
- 6 ножей: боевой, штык-нож, керамбит, бабочка, кукри, тычковый.
- Гранаты: осколочная, светошумовая, дымовая. Бронежилет, шлем, набор сапёра.
- Скины на всё оружие и ножи (5 редкостей), 9 кейсов (в том числе тематические «Токио», «Европа», «Майами», «Киото»), инвентарь с продажей.
- Боевой пропуск на 30 уровней: бесплатная и премиум-ветка (премиум пока 0 ₴).
- Две валюты (кредиты и золото), магазин (пока всё по 0 ₴), ежедневная награда, уровни и звания.

## Графика

- Настоящие 3D-модели оружия и персонажа с анимациями, руки держат оружие (IK).
- Фото-текстуры (PBR), HDRI-освещение, физическое небо, тени, bloom, затенение GTAO.
- Пресеты «Низкий / Средний / Высокий / Ультра» и ручная настройка каждого параметра.
- **Лимит FPS: 30 / 60 / 90 / 120 / 144 / без лимита.**

## Управление на ПК

| Клавиша | Действие |
|---|---|
| WASD, мышь | движение, обзор |
| ЛКМ / ПКМ | огонь / прицел |
| R | перезарядка |
| 1–5, колесо, Q | оружие, гранаты, бомба |
| B | закупка |
| E (удерживать) | заложить / обезвредить бомбу |
| G | бросить бомбу |
| Пробел, Ctrl, Shift | прыжок, присед, тихий шаг |
| F | осмотр оружия |
| Tab, Esc | счёт, пауза |

На телефоне — настраиваемые кнопки (редактор расстановки в «Настройки → Сенсор») и гироскоп.

## Структура

```
index.html, css/style.css — интерфейс
js/main.js       — меню, экраны, закупка, настройки, игровой цикл
js/game.js       — матч: режимы, раунды, экономика, бомба, гранаты, стрельба
js/bots.js       — ИИ ботов
js/city.js       — конструктор городов: здания, неон, улицы, машины, освещение
js/citymaps.js   — городские карты
js/data.js       — каталог оружия, ножей, скинов, кейсов, магазина
js/skins.js      — профиль, инвентарь, валюты
js/weapons.js    — модели оружия, ножей, гранат
js/character.js  — модель бойца, анимации, IK
js/viewmodel.js  — руки и оружие от первого лица
js/maps.js       — карты, навигация ботов
js/render.js     — небо, свет, тени, пост-обработка
js/assets.js     — загрузка ассетов
js/hud.js, input.js, audio.js, effects.js, physics.js, textures.js, icons.js
assets/          — модели, текстуры, звуки, HDRI (см. LICENSES.md)
tools/build_assets.py — сборка ассетов из исходников
```
