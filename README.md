# MAXI STRIKE

Тактический онлайн-шутер в браузере (пока бои с ботами). Работает на ПК (мышь + клавиатура) и на телефоне (сенсорное управление). Ничего устанавливать не нужно: всё на чистом JavaScript + [three.js](https://threejs.org/).

## Как запустить

ES-модули не открываются через `file://`, поэтому нужен любой локальный веб-сервер:

```bash
python3 -m http.server 8000
```

Потом откройте http://localhost:8000 в браузере.
Чтобы играть с телефона в той же Wi-Fi-сети, откройте `http://<IP-компьютера>:8000`.

## Что уже есть

- **Режимы:** командный бой (до 5×5) и «каждый сам за себя», бои с ботами.
- **Боты:** 4 уровня сложности (Новичок / Боец / Ветеран / Профи), поиск пути по карте, реакция, разброс, стрейфы, «слышат» выстрелы.
- **Карты:** «Оазис» (пустынный город, три линии) и «Порт» (контейнеры, ближний бой).
- **Оружие:** AR-7, VX-9 (ПП), LR-50 (снайперка с прицелом), SG-12 (дробовик), P-12 (пистолет), нож (удар в спину убивает сразу). Отдача, разброс от движения/прыжка, хедшоты, перезарядка.
- **Скины и кейсы:** 72 скина (12 раскрасок × 6 видов оружия), 5 редкостей, 3 кейса, рулетка открытия. Кредиты ◆ за убийства и победы.
- **Настройки:** чувствительность мыши/сенсора/в прицеле, инверсия, FOV, качество графики, масштаб рендера, громкость, конструктор прицела.
- **Редактор расстановки кнопок** для телефона: перетаскивание, размер, прозрачность каждой кнопки, левая кнопка огня.
- HUD: радар, килфид, индикаторы урона, хитмаркеры, таблица счёта (Tab), серии убийств.

## Управление на ПК

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ / ПКМ | обзор / огонь / прицел |
| Пробел | прыжок |
| Ctrl или C | присесть |
| Shift | тихий шаг |
| R | перезарядка |
| 1 / 2 / 3, колесо, Q | смена оружия |
| Tab | счёт |
| Esc | пауза |

## Структура

```
index.html        — разметка меню и HUD
css/style.css     — стили
js/main.js        — меню, арсенал, кейсы, настройки, игровой цикл
js/game.js        — матч: стрельба, урон, возрождение, счёт
js/bots.js        — ИИ ботов
js/maps.js        — карты, навигационная сетка, A*
js/physics.js     — коллизии и лучи
js/weapons.js     — характеристики и модели оружия
js/skins.js       — скины, кейсы, профиль
js/viewmodel.js   — оружие от первого лица
js/character.js   — модели бойцов
js/input.js       — клавиатура/мышь и сенсорное управление
js/hud.js         — интерфейс боя
js/audio.js       — синтезированные звуки
js/textures.js    — процедурные текстуры
```
