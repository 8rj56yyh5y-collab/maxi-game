# Лицензии ассетов

Код игры — собственный. Сторонние ассеты в папке `assets/`:

| Что | Источник | Лицензия |
|---|---|---|
| Модели оружия `assets/weapons/*.glb` | «Flat Guns West / East» (OpenGameArt), через [petroulacl/fps-asset-kit](https://github.com/petroulacl/fps-asset-kit) | CC0 |
| PBR-текстуры `assets/tex/*` | [ambientCG](https://ambientcg.com), через fps-asset-kit | CC0 |
| Звуки выстрелов `assets/sfx/shot_*` | Free Firearm Sound Library, через fps-asset-kit | CC0 |
| Звуки шагов `assets/sfx/step_*` | Fantozzi footsteps (OpenGameArt), через fps-asset-kit | CC0 |
| HDRI `assets/hdri/*` | [Poly Haven](https://polyhaven.com), из примеров three.js | CC0 |
| Персонаж `assets/chars/soldier.glb` | Пример `Soldier.glb` из [three.js](https://github.com/mrdoob/three.js) (модель и анимации Mixamo) | см. условия Mixamo / three.js |
| Библиотека `lib/` | [three.js](https://threejs.org) | MIT |

Скрипт сборки ассетов: `tools/build_assets.py`.
